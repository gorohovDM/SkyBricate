Дата: 20 октября 2026 года. База: origin/main `354f565b498093f42123a697cc77d8bc1b3dcdc3`; доработка поверх самостоятельного редактора этапа 4. По последней корректировке пользователя интерфейс строк из описания 5а включён в этап 4а. Знания, алгоритм выбора, правила крафта, применение и раскрытие свойств относятся к следующим заданиям и не реализованы.

## Данные и совместимость

Схема 3 сохраняет `systems[systemId].properties`, технические `categories`, обычные `components` и `rules`. Добавлена обязательная карта `specialComponents`: ключ componentId, значение — массив propertyId из каталога той же системы. Обычное назначение хранится в `components[componentId]`, особое — в `specialComponents[componentId]`. Особость относится только к связи systemId/componentId/propertyId; каталог содержит лишь name/description. Один propertyId допускается у разных компонентов с разными типами, но не в обоих массивах одного компонента.

Все карты и поля проверяются строго. Неизвестные поля, опасные ключи, отсутствующие обязательные поля, ссылки в другой каталог, дубликаты внутри массива и пересечение типов отклоняются до записи. Пустой массив допустим; пустая строка propertyId недопустима. Удаление свойства очищает оба типа и технические ссылки только исходной системы. Удаление компонента и сверка обслуживают обе карты. Отсутствующая система Fabricate по-прежнему не считается доказательством удаления её компонентов.

Полная корректная схема 2 сначала проверяется по прежнему контракту, затем копируется в память со schemaVersion 3 и пустыми specialComponents. Старые связи остаются обычными, правила и ID сохраняются. Само чтение не пишет. Первая успешная операция записи, включая сверку при открытии редактора, сохраняет схему 3. При отказе settings.set исходные байты setting не заменяются. Повреждённые и будущие схемы не сбрасываются и не нормализуются. Схема 1 по-прежнему требует отдельного подтверждённого сброса старых тестовых данных; миграции схемы 1 нет.

## Настройка и очередь записи

`skybricate.showSpecialProperties`: scope world, config true, Boolean, default false. Подписи локализованы. Настройка только управляет видимостью особой зоны и возможностью её редактирования, не изменяет prioritySpecial или участие связей в будущем алгоритме.

При выключении особые назначения сохраняются с исходным типом. Сохранение обычных строк и «Снять все» при скрытой зоне берут особые назначения из актуального snapshot внутри очереди DataStore. Совпадение обычного выбора с актуальной скрытой особой связью отклоняет всю запись. Прежний `setComponentProperties(systemId, componentId, propertyIds, options)` меняет только обычные связи и сохраняет особые.

Новый `setComponentAssignments(systemId, componentId, {ordinary, special}, {canWrite, editSpecial})` может записать оба типа атомарно. `editSpecial` по умолчанию false. Изменение special допускается, если оно явно разрешено вызывающим кодом, настройка включена при запросе и выполнении операции, а её ревизия не менялась за время ожидания очереди. Иначе сохраняются актуальные особые назначения. Проверки GM, действительности окна/контекста и наличия сохранённого компонента повторяются при выполнении.

Изменение настройки обновляет открытые окна через onChange: особые draft перечитываются из сохранённых данных, обычные сохраняются. Это поведение заранее описано в подсказке окна. Переход off→on во время очереди не разрешает устаревшему запросу перезаписать особые связи. При закрытии подписка удаляется. Внутри одного DataStore сохраняется общая очередь записи; между клиентами действует прежнее last-write-wins, распределённой блокировки нет.

## Интерфейс

Две зоны «Обычное свойство» и «Особое свойство» имеют одинаковые действия. Справа от подзаголовка находится «Добавить»; строка содержит select из каталога текущей системы и кнопку с корзиной, title и aria-label. Уже выбранный propertyId исключён из остальных списков обеих зон, включая скрытую особую. Удаление строки возвращает её свойство в доступные варианты. Пустая строка не сохраняется.

Настройка по умолчанию скрывает особую зону. «Снять все» очищает только видимые строки; запись требует «Сохранить свойства». Ошибки оставляют draft для повтора. Смена системы/компонента, перечитывание и закрытие сбрасывают draft. Ожидание блокирует повторные сохранения и навигацию. Неподходящий или утративший права контекст не пишет. Тексты свойств добавляются как текст, без HTML-интерпретации.
