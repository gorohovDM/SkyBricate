# SkyBricate
Дополнение для Fabricate: скрытые свойства категорий ингредиентов, особые свойства компонентов и постепенное открытие знаний персонажами. Планируется использование штатных проверок, переноса эффектов и создания результатов Fabricate.

Текущая версия 0.2.0 содержит каркас, слой хранения данных и справочник свойств отдельно для каждой системы крафта. В мастерском редакторе Fabricate выберите систему, откройте «Теги и категории» → «Свойства SkyBricate». Вкладка оформлена по аналогии с соседними справочниками: описание, поля названия и описания с кнопкой «Добавить», количество свойств и карточки со стандартной иконкой тега, названием, редактированием и удалением. Поиск пока отключён с пояснением; использование свойств пока не рассчитывается. Выбора иконок нет. Вкладка доступна мастеру при любом режиме выбранной системы; свойства пока не применяются при крафте.

Переименование сохраняет ID и связи. Удаление требует отдельного подтверждения и очищает назначения категориям, компонентам и порядок правил только в выбранной системе. Вкладка показывает ожидание сохранения, подтверждает успех после записи и сохраняет ввод при ошибке для повторной попытки. Панели справочника в настройках крафта больше нет.

Данные сохраняются в собственном скрытом world setting, схема 2. Изменять их может мастер. Каталоги, назначения категориям/компонентам и правила изолированы по системе. Старые тестовые данные схемы 1 с общим справочником не мигрируются: вкладка предлагает явный сброс с отдельным подтверждением удаления всех старых свойств, назначений и правил SkyBricate в мире. Сбрасывается только skybricate.data; данные Fabricate не меняются. Повреждённые, неизвестные и будущие схемы отклоняются без перезаписи и не получают кнопку сброса.

Интерфейс назначений и правил, знания персонажей, применение правил к крафту и раскрытие свойств пока не реализованы. При одновременной записи разных клиентов мастера действует правило последней записи; отдельной межклиентской блокировки нет. Кнопка «Перечитать справочник» обновляет данные, включая изменения другого мастера; несохранённый ввод при перечитывании, смене вкладки или экрана теряется.

Изучена только версия Fabricate 1.9.10. Монтаж четвёртой вкладки проверен с настоящими Svelte-компонентами TagsCategoriesView/VocabularyPanel этой версии в тестовом DOM, включая штатные вкладки и форму добавления, четыре вкладки с клавиатурой/ARIA, смену системы и повторный монтаж. Адаптер сохраняет штатные навигационные обработчики и черновики Fabricate. Целевые версии Foundry VTT — 13–14; запуск в Foundry, темы, размеры и реальные диалоги навигации в работающем мире не проверялись. При другой версии Fabricate или отсутствии необходимых API модуль отключается и сообщает мастеру причину. Неизвестная структура редактора блокирует вкладку и запись; при обнаружении несовместимого контракта мастер получает уведомление.

## Сборка для разработки

Требуется Node.js 22 или новее. Для тестов выполните `npm ci`: happy-dom и Svelte используются только при разработке, устанавливаемый модуль внешних зависимостей не имеет. Команда `npm run build` создаёт `dist/skybricate.zip` и `dist/module.json`. Архив воспроизводим: содержит только явный список runtime-файлов с фиксированными ZIP timestamps. `/docs`, `.reference`, тесты, node_modules и служебные файлы в него не попадают. Проверки: `node --test tests/regression.test.mjs`.

Дополнительная адресная проверка исходного Svelte-контракта: `node --conditions=browser tools/check-fabricate-editor.mjs`. Она требует отдельную локальную копию Fabricate в `.reference/fabricate` на SHA `5bf36ddf950619317e41737acd3bfa1305591a26` (либо путь первым аргументом) и не входит в обычные регрессионные тесты. Проверка не запускает Foundry и не подтверждает оформление в его темах.

Поля `manifest` и `download` подготовлены для GitHub Releases репозитория gorohovDM/SkyBricate. Адрес манифеста постоянный, адрес архива привязан к версии. Для будущего выпуска нужно обновить версию и адрес архива, собрать пакет и разместить оба файла в соответствующем релизе. На этапе каркаса релиз и тег не публикуются; доступность адресов обновления не подтверждена.
