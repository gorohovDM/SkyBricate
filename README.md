# SkyBricate
Дополнение для Fabricate: скрытые свойства категорий ингредиентов, особые свойства компонентов и постепенное открытие знаний персонажами. Планируется использование штатных проверок, переноса эффектов и создания результатов Fabricate.

Текущая версия 0.2.0 содержит каркас, слой хранения данных и редактор общего справочника свойств. В мастерском редакторе Fabricate откройте настройки крафта системы с режимом «Алхимия»: панель SkyBricate позволяет создавать и изменять название и описание свойства. Справочник общий для всех систем. Переименование сохраняет ID и связи; удаление требует подтверждения и очищает назначения категориям, компонентам и порядок правил во всех системах. Панель показывает ожидание сохранения, подтверждает успех после записи и сохраняет введённые значения при ошибке для повторной попытки.

Данные сохраняются в собственном world setting. Изменять их может мастер; повреждённые данные или неизвестная версия схемы отклоняются без перезаписи. Слой хранения также содержит назначения категориям и особые свойства компонентов, настройки правил отдельно для каждой системы крафта. Интерфейс назначений и правил, знания персонажей, применение правил к крафту и раскрытие свойств пока не реализованы. При одновременной записи разных клиентов мастера действует правило последней записи; отдельной межклиентской блокировки нет. Кнопка «Перечитать справочник» обновляет данные панели, включая изменения другого мастера; несохранённый ввод при перечитывании или смене экрана теряется.

Изучена только версия Fabricate 1.9.10. Монтаж панели проверен с настоящим Svelte-компонентом настроек этой версии в тестовом DOM, включая смену системы, режима и повторный монтаж. Целевые версии Foundry VTT — 13–14; запуск в Foundry и совместимость в работающем мире не проверялись. При другой версии Fabricate или отсутствии необходимых API модуль отключается и сообщает мастеру причину. Неизвестная структура редактора блокирует панель и запись; при обнаружении несовместимого контракта мастер получает уведомление.

## Сборка для разработки

Требуется Node.js 22 или новее. Для тестов выполните `npm ci`: happy-dom и Svelte используются только при разработке, устанавливаемый модуль внешних зависимостей не имеет. Команда `npm run build` создаёт `dist/skybricate.zip` и `dist/module.json`. Архив воспроизводим: содержит только явный список runtime-файлов с фиксированными ZIP timestamps. `/docs`, `.reference`, тесты, node_modules и служебные файлы в него не попадают. Проверки: `node --test tests/regression.test.mjs`.

Дополнительная адресная проверка исходного Svelte-контракта: `node --conditions=browser tools/check-fabricate-editor.mjs`. Она требует отдельную локальную копию Fabricate в `.reference/fabricate` на SHA `5bf36ddf950619317e41737acd3bfa1305591a26` (либо путь первым аргументом) и не входит в обычные регрессионные тесты. Проверка не запускает Foundry и не подтверждает оформление в его темах.

Поля `manifest` и `download` подготовлены для GitHub Releases репозитория gorohovDM/SkyBricate. Адрес манифеста постоянный, адрес архива привязан к версии. Для будущего выпуска нужно обновить версию и адрес архива, собрать пакет и разместить оба файла в соответствующем релизе. На этапе каркаса релиз и тег не публикуются; доступность адресов обновления не подтверждена.
