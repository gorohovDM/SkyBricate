# SkyBricate
Дополнение для Fabricate: скрытые свойства категорий ингредиентов, особые свойства компонентов и постепенное открытие знаний персонажами. Планируется использование штатных проверок, переноса эффектов и создания результатов Fabricate.

Текущая версия 0.1.0 — каркас: манифест, загрузка, проверка совместимости и русская/английская локализация сообщений. Свойства, знания, интерфейс и изменение крафта пока не реализованы.

Изучена только версия Fabricate 1.9.10. Целевые версии Foundry VTT — 13–14; запуск в Foundry и совместимость в работающем мире не проверялись. При другой версии Fabricate или отсутствии необходимых API каркас отключается и сообщает мастеру причину.

## Сборка для разработки

Требуется Node.js 22 или новее, внешних зависимостей нет. Команда `npm run build` создаёт `dist/skybricate.zip` и `dist/module.json`. Архив воспроизводим: содержит только явный список runtime-файлов с фиксированными ZIP timestamps. `/docs`, `.reference`, тесты и служебные файлы в него не попадают. Проверки: `node --test tests/regression.test.mjs`.

Поля `manifest` и `download` подготовлены для GitHub Releases репозитория gorohovDM/SkyBricate. Адрес манифеста постоянный, адрес архива привязан к версии. Для будущего выпуска нужно обновить версию и адрес архива, собрать пакет и разместить оба файла в соответствующем релизе. На этапе каркаса релиз и тег не публикуются; доступность адресов обновления не подтверждена.
